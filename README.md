# EX No.5.2.DESIGN THE 3D MODEL AS PROVIDED AND CONVERT TO ORTHOGRAPHIC VIEW
## DATE:

## AIM: 
To create orthographic view of given 3D model

## REQUIREMENTS: 
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE:
Step 1: Open Autodesk Fusion 360 
1. Open Autodesk Fusion 360 on the computer. 
2. Sign in to your Autodesk account. 
3. Select New Design to create a new project. 
4. Set the units to millimeters (mm). 

Step 2: Create the Tabletop Sketch 
1. Select the Create Sketch option from the toolbar. 
2. Choose the XY plane. 
3. Select the Rectangle tool. 
4. Draw a rectangle on the sketch plane. 
5. Apply the dimensions using the Dimension tool. 
6. Set the length as 30 mm and width as 30 mm. 
7. Ensure that the rectangle is properly positioned. 
8. Click Finish Sketch.

Step 3: Extrude the Tabletop 
1. Select the completed rectangular sketch. 
2. Click the Extrude option from the Create menu. 
3. Enter the extrusion distance as 4 mm. 
4. Check the preview to ensure the correct thickness. 
5. Click OK to complete the extrusion. 
The square tabletop is now created.

<img width="719" height="691" alt="{5F2EB114-C237-41F1-8E88-636E7C1C2994}" src="https://github.com/user-attachments/assets/d0a495b4-d2cd-452e-bed5-294d885867ea" />

Step 4: Create the Table Legs 
1. Select the bottom face of the tabletop. 
2. Click Create Sketch. 
3. Choose the Rectangle tool. 
4. Draw four small square profiles near the four corners of the tabletop. 
5. Apply dimensions to each square. 
6. Set the length and width of each leg profile to 2 mm × 2 mm. 
7. Position one leg at each corner. 
8. Click Finish Sketch.

Step 5: Extrude the Four Legs 
1. Select all four rectangular leg profiles. 
2. Click the Extrude option. 
3. Enter the extrusion distance as 30 mm.

<img width="715" height="438" alt="{E054C85B-955D-4F67-8132-8FE895896F66}" src="https://github.com/user-attachments/assets/9e21e645-60a6-40c5-8a1d-0d0ca9f67206" />

4. Set the extrusion direction downward from the tabletop. 
5. Check the preview to ensure that all four legs are properly connected. 
6. Click OK. 
Now, the four legs are attached to the tabletop.
 
Step 6: Finalize the Table Model 
1. Check whether all four legs are properly connected to the tabletop. 
2. Use the Orbit tool to rotate the model. 
3. Use the Zoom tool to view the model clearly. 
4. Apply the Fillet tool if rounded edges are required. 
5. Check the overall dimensions of the table. 
6. Ensure that the model matches the given engineering drawing.

Step 7: Save the Design 
1. Click the Save option. 
2. Enter a suitable file name. 
3. Select the required project location. 
4. Save the completed 3D table model.
